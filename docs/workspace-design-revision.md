# INS LAND 工作台深化修改意见

| 范围 | 修改 | 验收 |
| --- | --- | --- |
| 共用界面 | 浅暖灰与玫瑰粉作阅读底色，深色集中于主视觉。压缩章节页头，中文负责操作，花体用于展示，金额和日期对齐 | 四页首屏各有一个主角，手机上标题和关键操作同屏 |
| 年度总览 | 封面与年度时间带合并，邻片预览，跟随项目色显示活动周期和周中窗口 | 切换 S02、S07，日期和时间带同步，跨季与跨年正确，能打开项目 |
| 预算看板 | 全年规划与 S/A 结算明确范围。同尺度显示季度计划与实际，支持点击查看对应口径的结算明细 | 规划与实际的时间归属可辨识，展开可看搭建、体验和结算时间 |
| 项目规划 | 卡册采用有厚度的项目封套，清单压低封面并露出常用字段，原位展开 | 切换显示方式保留筛选与展开状态，预算可单独折叠 |
| 资源分析 | 首屏展示季度覆盖、并行峰值与空档。周期矩阵可按高峰日期筛查。类型同时展示项目数和预算占比 | 高峰与空档按日历计算，跨季项目可查，浏览权限保持有效 |

开屏沿用现有入口。发布前复查桌面和手机的封面联动、预算下钻、项目切换及分析筛选。
